# Power BI Dashboard Specification

## Page 1: Executive Overview
**Goal**: Provide a high-level view of business health.
- **KPI Cards**:
    - Total Revenue
    - Total Transactions
    - Success Rate
    - Failure Rate
    - Average Transaction Value (ATV)
- **Visuals**:
    - **Revenue Trend**: Line chart showing monthly revenue growth.
    - **Payment Method Breakdown**: Donut chart showing transaction volume by UPI, Card, etc.
    - **Top 5 Merchants**: Bar chart showing revenue by merchant.

## Page 2: Transaction Analytics
**Goal**: Analyze transaction health and geographical performance.
- **Visuals**:
    - **Success vs Failure Analysis**: Stacked bar chart by payment method.
    - **Transactions by State**: Map visual showing volume across India.
    - **Transactions by Device**: Pie chart (Android vs iOS vs Web).
    - **Monthly Growth**: Area chart showing % growth MoM.

## Page 3: Merchant Analytics
**Goal**: Deep dive into merchant-level performance.
- **Visuals**:
    - **Merchant Revenue Ranking**: Funnel chart or sorted bar chart.
    - **Merchant Success Rate**: Scatter plot showing Success Rate vs Transaction Volume.
    - **Gateway Performance**: Matrix table showing Success Rate and Fees by Gateway.

## Theme & Branding
- **Color Palette**: Razorpay Blue (#02042B), Success Green (#2ECC71), Alert Red (#E74C3C).
- **Font**: Inter / Segoe UI.
